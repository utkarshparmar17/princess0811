# Princess Janvi Day

A React, Vite, and Tailwind CSS greeting experience for Princess Janvi.

## Run locally

```sh
npm install
npm run dev
```

Sign in with `janvi` and `0811` to open the diary. The song in `public/princess-song.mpeg` starts after login and loops continuously; the player controls can pause or resume it.

## Build and lint

```sh
npm run build
npm run lint
```
